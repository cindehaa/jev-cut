[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/cindehaa/jev-cut&env=TYPESAFE_API_KEY)

Add `TYPESAFE_API_KEY` in the Vercel project env. Without it the stand-in chooser still runs so you can see timing.
